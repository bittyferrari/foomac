## Features

- **Add a folder** (⌘O or drag it in) — scans every subfolder for mp3, m4a, aac, flac, wav and aiff
- **Zip files work like folders**, just like foobar2000 — no unzipping; Big5 / GBK / Shift-JIS file names, ZIP64
- **Folder tree** sidebar like foobar2000's Album List — pick any level to see every song under it
- Table playlist with sortable columns, multi-keyword search, ID3 tags (title, artist, album, track, year, genre, bitrate)
- Repeat playlist / repeat one / **shuffle that plays the whole list before reshuffling**
- Media keys and Control Center "Now Playing"
- Gradient themes (Ocean, Forest, Grape, Neon, Sunset, Sakura, Lemon) or pick your own colors; window transparency
- **RGB gaming lights** — 34 effects that can pulse to the music, plus a real-time **spectrum / waveform visualizer**
- 4 languages: English, 繁體中文, 简体中文, 日本語

## Install

1. Download **Foomac.dmg** and drag Foomac into Applications.
2. Open it — it's signed with a Developer ID and notarized by Apple.
3. Add a music folder with ⌘O.

Requires **macOS 14 Sonoma or later**, Apple silicon or Intel. Free — no ads, no tracking.
